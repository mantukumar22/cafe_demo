1. server/middleware/upload.js
   - Configure Multer with diskStorage
   - destination: dynamically set to server/uploads/{category}/
     based on req.body.category field sent from frontend
   - filename: Date.now() + '-' + originalname (sanitized)
   - fileFilter: allow only image/jpeg, image/png, image/webp
   - limits: maxFileSize 5MB, maxFiles 10 per request

2. server/db/images.json
   - JSON array storing metadata of every uploaded image:
   [
     {
       "id": "uuid-here",
       "category": "inner-view",
       "filename": "1700000000-interior.jpg",
       "path": "/uploads/inner-view/1700000000-interior.jpg",
       "label": "Cozy Corner",
       "uploadedAt": "2024-01-01T10:00:00Z"
     }
   ]
   - On every upload, append the new entry to this JSON file
   - This is your lightweight DB — no MongoDB needed

3. server/controllers/imageController.js
   - uploadImages(req, res):
       * Validate admin key from request header 'x-admin-key'
       * Use Sharp to resize each image to max 1200px wide,
         compress to 80% quality, save as WebP in the folder
       * Append metadata to images.json
       * Return success response with uploaded file paths
   - getImagesByCategory(req, res):
       * Read images.json
       * Filter by ?category= query param
       * Return array of image objects
   - getAllImages(req, res):
       * Return full images.json
   - deleteImage(req, res):
       * Validate admin key
       * Remove file from disk
       * Remove entry from images.json

4. server/routes/images.js
   POST   /api/images/upload         ← upload (admin only)
   GET    /api/images?category=hero  ← fetch by category
   GET    /api/images/all            ← fetch all
   DELETE /api/images/:id            ← delete by id (admin only)

5. server/server.js
   - Serve /uploads as static: app.use('/uploads', express.static('uploads'))
   - Mount image routes and contact routes
   - Serve client/dist in production

## Local Development

  cd server && npm install && npm run dev      ← runs on port 5000
  cd client && npm install && npm run dev      ← runs on port 5173

## Production Build

  cd client && npm run build                  ← outputs to client/dist/
  cd server && node server.js                 ← serves dist + API

## Deploying to Render.com (Backend + Full Site)

  Step 1: Push entire project to GitHub (public or private repo)
  Step 2: Go to render.com → New → Web Service
  Step 3: Connect your GitHub repo
  Step 4: Set these settings:
    - Root Directory: server
    - Build Command: npm install
    - Start Command: node server.js
    - Environment: Node
  Step 5: Add Environment Variables in Render dashboard:
    PORT, EMAIL_USER, EMAIL_PASS, RECEIVER_EMAIL,
    CLIENT_URL, ADMIN_SECRET_KEY, NODE_ENV=production
  Step 6: Under Disks (Render paid) or note:
    ⚠️ Render free tier has ephemeral storage —
    uploaded images will reset on redeploy.
    Solution: Use Cloudinary free tier for persistent image storage.

## Persistent Image Storage with Cloudinary (Recommended for Production)

  Step 1: Sign up at cloudinary.com (free tier: 25GB storage)
  Step 2: Get your: CLOUD_NAME, API_KEY, API_SECRET
  Step 3: npm install cloudinary multer-storage-cloudinary
  Step 4: In upload.js, replace Multer diskStorage with
          CloudinaryStorage — images upload directly to cloud
  Step 5: Store returned Cloudinary URL in images.json instead of local path
  Step 6: Add to server/.env:
    CLOUDINARY_CLOUD_NAME=your_cloud_name
    CLOUDINARY_API_KEY=your_key
    CLOUDINARY_API_SECRET=your_secret

## Deploying Frontend to Vercel (Optional — faster CDN)

  Step 1: cd client && npm run build
  Step 2: Go to vercel.com → Import Project → Select repo
  Step 3: Set Root Directory: client
  Step 4: Add env variable: VITE_API_URL=https://your-render-url.onrender.com
  Step 5: Deploy — Vercel auto-deploys on every git push

## Admin Panel Access in Production

  Visit: https://your-site.com/admin
  Enter the ADMIN_SECRET_KEY you set in env
  Upload images → they appear on website instantly
